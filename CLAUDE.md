# Instructions for AI assistants

Read and follow [RULES.md](RULES.md) before making any change. The most important rules:

- Never commit without explicit approval to commit, and never push without a second, separate approval to push.
- Respect the layer boundaries and security rules in RULES.md sections 3 and 4.
- Prefer plain, readable code, and explain non-obvious changes in the summary you give for review.

Context: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the design, [docs/DECISIONS.md](docs/DECISIONS.md) for decisions already made (do not reopen them without asking), and [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md) for milestone and commit order.
